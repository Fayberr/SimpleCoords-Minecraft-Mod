# SimpleCoords 2.2.0

- Show targeted block coordinates beneath the biome, at the bottom of the HUD.
- Optional target subchunk coordinates, namespaced block type and individual block state properties.
- Target details disappear when looking away from a block. Uses the normal crosshair target and reach.
- Configure each option in Modern Config, the built-in settings screen, or `/simplecoords set show_target`, `show_target_subchunk`, `show_target_type`, and `show_target_state`.
- Target coordinates default on; extra details default off. HUD position editor previews the selected target details.
