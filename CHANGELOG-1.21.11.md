# SimpleCoords 2.2.0 for Minecraft 1.21.11

- Backport the current Fabric HUD, including biome and targeted block options.
- Compile for Java 21 and remap the release jar for Minecraft 1.21.11.
- Use the built-in settings screen and HUD drag editor. ModMenu is optional.
- Modern Config has no compatible 1.21.11 target and is not required.
