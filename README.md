# SimpleCoords

A lightweight client-side HUD for Minecraft 1.21.1 (NeoForge) that displays your coordinates and facing direction.

## Features
- Displays XYZ coordinates with custom precision (0-5 decimals).
- Displays Subchunk (relative) coordinates (0-15).
- Displays current Facing direction.
- Custom HUD positioning (X and Y coordinates).
- In-game Config support via the Mods menu.
- Command-line toggle: `/simplecoords toggle`.

## Installation
Place the `.jar` file in your Minecraft `mods` folder.

## Commands
- `/simplecoords toggle` - Show or hide the HUD.

## Configuration
Access the configuration via the NeoForge Mods menu. You can toggle the HUD on or off, change position, and adjust precision there.
