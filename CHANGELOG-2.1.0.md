# SimpleCoords 2.1.0 for Minecraft 26.3

- Added the current biome to the HUD, with a Show Biome setting and client command.
- The biome follows the same player or camera position as the coordinates.
- Added optional Modern Config support for settings opened through commands or Mod Menu.
- Kept the built-in settings screen when Modern Config is absent, with a compact layout and biome-aware HUD editor.
